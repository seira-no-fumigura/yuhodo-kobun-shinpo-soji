## 作品について

古文真宝の前集・後集と楚辞の原文（訓点付き）。例言のあと、前集（詩）・後集（文）と楚辞を収める。有朋堂書店が『漢文叢書』の一冊として出した、原文に訓点を付けた版。昭和 3 年（1928 年）刊。

## 底本

- [漢文叢書](https://dl.ndl.go.jp/pid/1118541)（有朋堂・1928年）。国立国会図書館の全文テキスト（OCR）のまま

国立国会図書館デジタルコレクションの「インターネット公開（保護期間満了）」の資料です。

## 本文の作り方

国立国会図書館デジタルコレクション（インターネット公開）の全文テキスト（OCR）をそのまま収めた。1 段落が底本の 1 コマ（見開き）。校正はしていないので、振り仮名や柱の混じり、読み違いが残る。

## ファイル

| パス | 中身 |

段落ID（例: `yuhodo-kobun-shinpo-soji-0001`）は、本文を直しても変わりません。データの形は雲居の文庫の作品リポジトリと同じです。
